# Requisitos da Loja Virtual

## Objetivo

Desenvolver um sistema de loja virtual que permita aos clientes consultar produtos, adicionar itens ao carrinho, realizar pedidos e acompanhar suas compras.

## Principais funcionalidades

- Cadastro de clientes;
- Autenticação de usuários;
- Consulta e pesquisa de produtos;
- Gerenciamento do carrinho;
- Realização de pedidos;
- Processamento de pagamentos;
- Acompanhamento de pedidos;
- Gerenciamento de produtos;
- Gerenciamento de pedidos;
